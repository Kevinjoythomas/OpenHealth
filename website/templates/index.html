Architecture
Built on proven medical AI techniques

Fine-Tuned Llama 3 8B

LoRA-adapted on 112K+ real doctor-patient conversations from the ChatDoctor dataset. Learns medical tone, diagnosis patterns, and treatment recommendations.

Hybrid RAG Retrieval

Combines BM25 keyword search with dense vector search via Reciprocal Rank Fusion. Catches both exact medical terms and semantic synonyms.

Clinical Document Grounding

Answers grounded in WHO guidelines, ACC/AHA clinical practice guidelines, and peer-reviewed medical PDFs. Sources cited with every response.

Honest Fallbacks

When the knowledge base doesn't cover a topic, the system says so. No fabricated citations. No false confidence. Safety-first design.

Microservices Architecture

Auth, Chat Orchestrator, Retrieval, and API Gateway run as independent services. Each testable, deployable, and scalable on its own.

JWT Authentication

Secure token-based auth with bcrypt password hashing, refresh tokens, and role-based access. No plaintext passwords ever stored.

Pipeline
From question to grounded answer
Step 01

Patient describes symptoms

Plain language input — no medical terminology required. "I have chest tightness and difficulty breathing."

Step 02

Hybrid retrieval searches clinical docs

BM25 matches exact terms. Vector search understands "difficulty breathing" means "dyspnea". RRF fuses both ranked lists.

Step 03

Context injected into LLM prompt

Top-ranked document chunks are prepended to the prompt. The model answers with both its training knowledge and retrieved evidence.

Step 04

Grounded response with citations

The answer includes source references. If no relevant documents were found, it says so honestly — no fabricated citations.
