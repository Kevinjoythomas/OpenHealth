The Response Pipeline

01

User Query

Natural language symptoms sent to API Gateway. JWT validated, rate limited, forwarded to Chat Orchestrator.

02

Hybrid Search

Retrieval Service runs BM25 + ChromaDB in parallel. Top-5 docs fused with RRF scoring.

03

Context Injection

Only docs above relevance threshold (RRF ≥ 0.020) are injected. Low-confidence sources filtered out.

04

LLM Response

Fine-tuned Llama 3 8B generates clinical guidance via Ollama. Sources cited when retrieval is confident.

Safety Framework

  • verified_user

    Emergency Escalation Scoring

    Rubric axis dedicated to safety referrals. Full pipeline scored 2/2 on all 4 safety-required test cases — chest pain, suspected TIAs, polypharmacy, and complex diabetes.

  • history_edu

    Grounded Source Citation

    Sources are only cited when RRF score ≥ 0.020, meaning both BM25 and vector search agreed on the document. Low-confidence retrieval falls back to model training knowledge.

  • health_and_safety

    Relevance Threshold Filtering

    Prevents hallucinated citations. When the corpus lacks coverage, the model answers from fine-tuning rather than injecting irrelevant PDF chunks.

Infrastructure Design

API Gateway (:5000) → Auth (:5001) · Chat Orchestrator (:5002) → Retrieval (:5003) → BM25 + ChromaDB + RRF → Ollama GGUF. Static frontend on Vercel, backend tunnelled via ngrok. Ingestion worker via Celery + RabbitMQ.

REST API · Open Source

Designed for Extensibility

OpenHealth exposes a clean REST API across 4 services. Swap Ollama for any model backend, ChromaDB for any vector store, or BM25 for any keyword retriever with minimal config changes. Runs locally without Docker — SQLite and fakeredis substitute automatically in dev mode. 

import requests

# Send a clinical query to the OpenHealth API
token = "your_jwt_token"
session_id = "your_session_id"

response = requests.post(
    f"http://localhost:5000/v1/chat/sessions/{session_id}/messages",
    headers={"Authorization": f"Bearer {token}"},
    json={"message": "I have chest pain radiating to my left arm"}
)

data = response.json()
print(data["answer"])   # RAG-grounded clinical response
# Sources: Chest Pain Protocol (RRF: 0.031), ACS Guidelines (RRF: 0.028)
